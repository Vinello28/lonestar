Clean Architecture Stack

Strict dependency inversion across Rust (`lonestar-core`) and Svelte 5 Runes (`src/`).

1. Domain Layer

Pure Rust entities (`DiagramModel`, `Actor`, `Link`) and the formal iStar 2.0 validator with zero UI dependencies.

2. Application Layer

`ModelService` use cases, repository ports, auto-layout, and Svelte 5 `$state` / `$derived` stores with Undo/Redo.

3. Infrastructure Layer

Bidirectional piStar v2.0 JSON interop codec, disk repository, canonical templates, and Hi-Res PNG/SVG exporter.

4. Presentation Layer

Tauri v2 IPC commands + responsive Svelte 5 SVG board delivering 60fps interaction across Linux, Windows, and macOS.
